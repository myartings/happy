# Domain Docs

Before exploring, read `CONTEXT-MAP.md` when present and use it to select the
applicable `CONTEXT.md`; otherwise read the root `CONTEXT.md`. Read relevant
ADRs under `docs/adr/` and context-local ADRs when the repository defines them.

Use the glossary's canonical terms. If a needed term is absent, reconsider
whether it belongs to the domain or route the gap through `domain-modeling`.
Surface conflicts with an existing ADR explicitly rather than silently
overriding it. Missing optional domain documents are not errors.
