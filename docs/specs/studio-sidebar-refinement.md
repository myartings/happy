# Studio Sidebar Refinement

## Goal

Bring the already accepted packaged-desktop Studio sidebar closer to the
accepted Pencil v2 typography hierarchy without changing its functional layout
or previously accepted frame and row geometry.

## Acceptance criteria

- Studio session titles use the v2 13 pt semibold role.
- Primary metadata remains 11 pt and secondary runtime/status metadata uses the
  quieter 10 pt role.
- The Settings footer uses the v2 compact 44 pt footer rhythm and 13 pt label.
- Existing 316 pt sidebar, 62 pt rows, 38 pt controls, selection, status,
  navigation, menus, and settings action remain unchanged.
- The changes apply only to packaged-desktop Studio; Default and mobile paths
  remain unchanged.
- Automated verification does not constitute visual acceptance; the integrated
  desktop screenshot is returned to the user for approval.
